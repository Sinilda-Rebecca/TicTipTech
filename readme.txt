Project Name: TicTip Tech Website
Version: 1.0.0 (increment by +1)
Author: TicTip
Company: TicTip Tech

Description:
This project contains the complete source code for the TicTip Tech website,
including all HTML, CSS, JavaScript, and media assets. The website is fully
responsive and optimized for mobile, tablet, and desktop viewing.

Folder Structure:
- /css        → Stylesheets used across the website
- /js         → JavaScript functionality and UI interactions
- /images     → Website images, icons, and graphics
- /assets     → Fonts, documents, and supporting files
- index.html  → Main homepage of the website

How to Use:
1. Open index.html in any modern browser.
2. Update or modify styles inside the /css folder.
3. Add or edit JavaScript functionality inside the /js folder.
4. Keep all images inside the /images folder to avoid broken links.
